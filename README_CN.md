# SkillsHub

SkillsHub 是一个本地优先的桌面应用，用来收集、查看、整理并安装 AI agent skills 到多个 coding 工具。

[English](README.md)

> **免责声明**
>
> SkillsHub 是独立的非官方应用。它与 Anthropic、OpenAI、GitHub、skills.sh、MiniMax 或其他受支持平台、发布方、商标所有者均无隶属、背书或赞助关系。

## 它解决什么问题

SkillsHub 把技能的长期保存和平台安装拆开：

- **技能资源库** 是默认入口，用于保存通过 `npx skills` 导入的技能，以及从本地文件夹添加的技能。
- **中央技能库** 通常是 `~/.agents/skills/`，用于把你明确选择共享的技能放入兼容目录。
- **软件平台** 是具体工具自己的 skills 目录，例如 Claude Code、Codex CLI、Cursor、Gemini CLI、OpenClaw 等。
- **技能集合** 用于把技能资源库中的技能组成可复用分组，并批量安装到目标位置。
- **项目目录** 是项目级安装目标。SkillsHub 会管理每个项目目录下的 `.agents/skills`，让技能资源库和中央技能库中的技能可以像安装到软件平台一样安装到项目中。

应用数据保存在 `~/.skillshub/db.sqlite`。从旧版本升级时，如果新数据库不存在，SkillsHub 会在首次启动时迁移已有的 `~/.skillsmanage/db.sqlite`。

## 核心能力

- 以技能资源库为默认工作流，**导入技能** 使用隔离的 `npx skills add owner/repo` 流程下载完整技能内容，再复制到技能资源库。
- **添加技能** 用于复制本地已经准备好的单个 skill 文件夹或合集文件夹，并与可追踪的 npx 导入技能区分管理。
- 导入技能只需要填写 `owner/repo`；可选填写技能名称，只导入仓库中的某一个技能。
- 可追踪来源的技能支持 **更新技能**：先检查来源仓库的更新标记，有变化时再重新下载并覆盖本地副本。
- 底部状态栏会显示导入、更新、安装等任务的实时状态，更新技能后可以查看成功、跳过和失败统计。
- 技能资源库目录视图按 `owner/repo` 这类来源路径分组，更贴近 `作者/项目/技能` 的本地结构。
- 技能资源库、中央技能库、软件平台和项目目录的目录视图支持按目录管理；资源库目录可按目录加入中央库、安装到软件平台或项目目录，平台和项目目录可按目录卸载。
- 技能资源库的标签、备注和来源信息在重新扫描、导入、刷新和检查更新后都会保留。
- 所有技能浏览页共用同一套“排序”和“视图”工具栏。排序字段点击后切换方向，目录视图与全部视图使用一致的筛选和排序逻辑。
- 单个技能和目录卡片使用一致的安装图标语义：数据库图标表示加入中央技能库，包安装图标表示安装到软件平台或项目目录。
- 技能卡片会分别显示创建日期和更新日期，并根据当前界面语言显示对应标签。
- 资源库技能可以直接安装到指定软件平台或项目目录，不强制加入中央技能库。
- 技能集合添加技能时从技能资源库选择，而不是只从中央技能库选择；集合中的资源库技能也可以继续安装到软件平台或项目目录。
- 资源库技能也可以一键加入中央技能库；中央技能库已有托管技能时，新检测到的本地平台和已配置的项目目录会自动纳入同步和侧边栏显示。
- 中央技能库支持目录视图、安全删除预览、平台安装状态和批量从平台卸载。
- 技能详情页默认以 Markdown 预览方式只读展示技能内容，右侧栏把时间、来源和存储路径合并到一个基本信息分区，减少重复字段。
- 设置页的软件平台管理支持编辑/删除内置平台、添加自定义平台、龙虾类/编程类分组、紧凑两列布局、内置/已检测数量统计，并区分本机已检测到目录和未检测到目录的平台。
- 设置页的项目目录管理位于软件平台下方，项目目录作为项目级安装目标使用 `.agents/skills`，并支持通过“浏览”按钮选择目录。
- 左侧栏的软件平台、龙虾类、编程类和项目目录都支持独立折叠。
- 支持本地 ZIP 备份和 WebDAV 备份/导入，包括测试连接、查看远端、上传备份、导入选中和删除选中；备份文件不会包含 API Key、Token 或密码类内容。
- 关于区域支持检查更新。
- 中英文界面、左下角系统/浅色/深色主题切换，侧边栏、提供商、语言选中态颜色统一，顶部区域去掉全局搜索框，主视图保留各页面自己的搜索和操作入口。

## 存储模型

SkillsHub 使用四个不同的存储概念：

| 区域 | 用途 | 常见路径 |
|------|------|----------|
| 技能资源库 | 长期保存导入或手动创建的技能 | `~/.skillshub/library` |
| 中央技能库 | 保存明确加入共享兼容目录的技能 | `~/.agents/skills` |
| 平台目录 | 某个工具自己的安装目标，通常是符号链接或复制文件 | 取决于平台 |
| 项目目录 | 项目级安装目标，管理在项目根目录下 | `<项目>/.agents/skills` |

从技能资源库直接安装技能时，只写入所选软件平台或项目目录。加入中央技能库时，会写入中央目录。中央技能库已有托管技能时，新检测到的本地平台和已配置的项目目录会自动纳入中央技能同步，并显示在侧边栏中。

技能集合只保存技能引用。添加技能时，选择范围来自技能资源库；安装集合或集合中的单个技能时，会以资源库中的技能为来源分发到软件平台或项目目录。

修改技能资源库路径、中央技能库路径、平台目录或项目目录不会自动改写已有软链接或副本；如果你确实移动了目录，需要按需重新安装相关技能。

## 支持的平台

内置平台可以在设置页编辑或删除。对内置平台的修改会写入本地配置文件，下次启动后仍然保留。

| 分类 | 示例 |
|------|------|
| 编程类 | Claude Code、Codex CLI、Cursor、Gemini CLI、GitHub Copilot、Kiro CLI、Warp、Windsurf、Trae、Aider、OpenCode、Continue、Qwen 等 |
| 龙虾类 | OpenClaw、AutoClaw、EasyClaw、QClaw、WorkBuddy 等 |
| 自定义 | 任意拥有稳定 skills 目录的本地平台 |

左侧栏默认只展示本机已存在对应 skills 目录的内置平台；也可以手动切换为显示全部平台。软件平台分组和项目目录列表都可以独立折叠。设置页的平台分组标题会同时显示内置平台总数和当前电脑已检测到的数量。

## 导入和添加技能

技能资源库把网络导入和本地添加分开：

- **导入技能**：只填写 GitHub `owner/repo`。SkillsHub 会在隔离临时目录中执行 `npx skills add owner/repo`，然后把下载到的完整技能文件夹复制到技能资源库。填写“技能名称”时，只导入仓库中的指定技能。
- **添加技能**：选择本地已经准备好的 skill 文件夹。它可以是单个技能目录，也可以是包含多个技能的合集目录。SkillsHub 会复制文件夹内容，并把来源标记为本地添加。

通过 `npx skills` 导入的技能会保存来源仓库、可选技能名和来源更新标记，用于后续“更新技能”。本地添加的技能没有远程来源，不会参与来源更新。

## 备份与迁移

SkillsHub 支持导出和导入完整本地备份文件。WebDAV 备份支持测试连接、查看远端备份列表、上传、选择远端备份恢复，以及删除选中的远端备份。

备份包含技能文件、来源信息、技能集合、自定义平台、普通应用配置和平台安装状态。API Key、Token 和密码类内容会被排除，恢复后需要重新填写。

## 隐私与安全

- SkillsHub 本地优先，不包含遥测。
- 只有在使用 `npx skills` 导入或更新、WebDAV 备份、检查更新或 AI 备注等网络功能时才会发起请求。
- 你选择保存的凭据会保存在本机；应用不会对本地设置做静态加密。
- 不要在 issue、PR、截图或日志中公开真实 Token、API Key、私有路径或其他敏感信息。

## 开发

### 环境要求

- Node.js LTS
- pnpm
- Rust stable toolchain
- Tauri v2 系统依赖：<https://v2.tauri.app/start/prerequisites/>

### 常用命令

```bash
pnpm install
pnpm tauri dev
pnpm build
pnpm test
pnpm typecheck
pnpm lint
cd src-tauri && cargo test
cd src-tauri && cargo clippy -- -D warnings
```

Vite 开发服务器默认使用 `24200` 端口。

## 发布

推送 `v0.20.1` 这样的版本 tag 后，GitHub Actions 会构建并发布桌面安装包。发布工作流会从 `CHANGELOG.md` 读取对应版本的 release notes，因此每次发布都必须有匹配的更新日志条目。

本地仍可使用分平台脚本打包：

| 平台 | 命令 |
|------|------|
| Windows | `pnpm package:release:windows -- -Version 0.20.1` |
| macOS | `pnpm package:release:macos -- -Version 0.20.1` |
| Linux | `pnpm package:release:linux -- -Version 0.20.1` |

只需要更新版本元数据时使用 `-VersionOnly`。

### 构建输出目录

Tauri 和本地打包脚本会有意区分不同输出目录：

| 路径 | 生成者 | 用途 | 是否用于发布 |
|------|--------|------|--------------|
| `dist/` | Vite | 前端构建产物，供 Tauri 打包进桌面应用 | 否 |
| `src-tauri/target/` | Cargo/Tauri | Rust 构建缓存、可执行文件和平台原始 bundle 输出 | 否 |
| `release-assets/` | 本地打包脚本和 GitHub Actions | 已重命名整理好的最终安装包和压缩包 | 是 |

本地打包完成后，只从 `release-assets/` 取发布文件。`dist/` 和 `src-tauri/target/` 视为构建内部目录，通常只在排查构建问题时查看。
